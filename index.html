Will this break my TV?

No. Every change runs safely inside your normal TV user account—never touching firmware, never requiring root, and always saving an exact backup of your TV first so you can undo everything with one command.

Why this feels faster than regular launcher apps

Most guides tell you to install Projectivy and flip on an "Override current launcher" switch. That trick leaves the heavy Google TV home screen running invisibly underneath, still eating 150–250 MB of memory and flashing every time you hit Home.

  • Ordinary override hack: Old home screen stays alive in memory, banner ads keep polling Wi-Fi, and pressing Home briefly flashes the old menu.
  • This toolkit's native swap: Assigns Projectivy to Android's official HOME role, pauses the bloated stock launcher cleanly, and shields Projectivy so Android never closes it.

Power user script, health check & factory undo

Comfortable with PowerShell, want to verify that the optimization stuck, or ready to revert your TV back to factory defaults? Everything is right here.

1. Install Android Platform-Tools (ADB)

Skip this if you already have ADB installed on your Windows PC.

winget install Google.PlatformTools
2. Clone the toolkit repository
git clone https://github.com/AadhithyaKC/tcl-androidtv-optimizer.git
cd tcl-androidtv-optimizer
3. Run the optimizer (replace with your TV's IP address)

Automatically snapshots your TV into ./backups/ first.

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Optimize-TCLTV.ps1 -TvIp "192.168.1.xx"
Check that Projectivy owns your Home button & inspect live free memory

Scroll horizontally on mobile to read each command cleanly.

adb shell cmd role get-role-holders android.app.role.HOME
adb shell settings get global standard_max_cached_processes
adb shell dumpsys meminfo --package-summary
One-Click Factory Undo

Reads your earliest pre-change backup in ./backups/ and restores your TV to its exact untouched state.

.\Restore-Defaults.ps1 -TvIp "192.168.1.xx"
01
Pre-Change Backup Snapshot Exports packages, settings, HOME role, and baseline RAM into ./backups/ first.
adb shell pm list packages -e > backup.txt
02
Native Default Home Screen Assigns Projectivy to Android's native HOME role and disables stock launchers.
cmd role add-role-holder android.app.role.HOME
03
Safe Accessibility Append Appends Projectivy without overwriting any existing remote button remappers.
settings put secure enabled_accessibility_services
04
Memory & Doze Shield Whitelists Projectivy so Android's memory manager never purges your home screen.
dumpsys deviceidle whitelist +com.spocky.projengmenu
05
TCL Telemetry & Ad Debloat Disables boot ad services, loggers, crash reporters, and background diagnostic daemons.
pm disable-user --user 0 com.tcl.bootadservice
06
App Pre-Compilation (AOT) Compiles Projectivy, Netflix, YouTube, Prime Video, and Hotstar for faster cold launches.
cmd package compile -m speed-profile -f <pkg>
07
Play Store Background Lock Stops silent background updates from wiping out compiled app speed profiles.
appops set com.android.vending RUN_IN_BACKGROUND ignore
08
2-App Background Memory Cap Keeps 2GB RAM TVs from choking on a dozen cached apps during 4K playback.
settings put global max_cached_processes 2
09
Passive Radio Quiet Mode Turns off continuous background Wi-Fi/BLE scans and repetitive captive-portal pings.
settings put global wifi_scan_always_enabled 0
10
Snappier 0.5x Menu Transitions Halves window and transition delays so every remote press feels immediate.
settings put global window_animation_scale 0.5
