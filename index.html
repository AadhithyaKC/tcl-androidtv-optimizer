Why This Works Better

Native OS HOME Role vs. Accessibility Override

Most guides tell you to enable Projectivy's internal "Override current launcher" toggle, which leaves the heavy Google TV launcher running underneath. We replace it at the Android OS role level.

✕ Standard Accessibility Override Hack

  • Stock Google TV launcher (launcherx) stays active in RAM consuming 150–250 MB continuously.
  • Pressing Home triggers an Accessibility intercept after the stock home screen briefly flashes or redraws.
  • Background banner ads and content recommendation feeds keep polling over Wi-Fi.

✓ Native android.app.role.HOME Assignment

  • Registers Projectivy as the OS-level home activity and disables launcherx / tvlauncher completely.
  • Projectivy's "Override current launcher" toggle is not required—Android boots straight into Projectivy.
  • Whitelists Projectivy in deviceidle so Android's Low Memory Killer never purges your home screen.

Hardware & Input Protection Guarantee

All operations run at non-root --user 0 level. Essential TV hardware packages (com.tcl.tvinput, com.tcl.tv, com.tcl.settings, com.tcl.systemserver) as well as active keyboards (default_input_method) and button remappers are strictly whitelisted so HDMI-CEC, picture calibration, and physical remote buttons never break.

Under The Hood

10 Automated ADB Optimization Subsystems

Every command executed by Optimize-TCLTV.ps1 and the interactive AI skill workflow is transparent and auditable.

1. Pre-Change Snapshot

Exports enabled/disabled packages, global/secure settings, HOME role, and baseline RAM into ./backups/ before touching a single setting.

adb shell pm list packages -e > backup.txt

2. Native Default Launcher

Assigns Projectivy to Android's native HOME role and disables stock Google TV & TCL launchers.

cmd role add-role-holder android.app.role.HOME

3. Safe Accessibility Append

Reads existing accessibility services first and appends Projectivy with a colon separator without overwriting button mappers.

settings put secure enabled_accessibility_services

4. Doze & Memory Shield

Whitelists Projectivy from Android's aggressive memory reaper so the home screen stays resident in RAM permanently.

dumpsys deviceidle whitelist +com.spocky.projengmenu

5. OEM Telemetry Debloat

Disables TCL loggers, crash reporters, boot ad services, diagnostic daemons, and unsolicited OTA popups.

pm disable-user --user 0 com.tcl.bootadservice

6. AOT Machine Code Compile

Pre-compiles Projectivy, Netflix, YouTube, Prime Video, Hotstar, and user apps via ART speed-profile.

cmd package compile -m speed-profile -f <pkg>

7. Play Store Background Lock

Prevents Google Play Store from running unannounced background auto-updates that overwrite compiled AOT binaries.

appops set com.android.vending RUN_IN_BACKGROUND ignore

8. Process Cap Tuning

Limits cached background processes to 2 on 2GB RAM TVs, eliminating ActivityManager memory thrashing during 4K playback.

settings put global max_cached_processes 2

9. Passive Radio Quiet Mode

Turns off continuous background Wi-Fi/BLE location scanning and disables repetitive HTTP captive-portal checks.

settings put global wifi_scan_always_enabled 0

10. 0.5x Animation Scaling

Halves window, transition, and animator duration scales for immediate visual feedback on every remote press.

settings put global window_animation_scale 0.5
